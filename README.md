# Shale-Namma Pride 🏫

A government school transparency app built with Kotlin, Firebase, and Gemini AI.

## Setup Instructions

1. Open this project in Android Studio
2. Connect to Firebase (Tools > Firebase)
3. Add your `google-services.json` to the `app/` directory
4. Add your Gemini API key in `GeminiService.kt`
5. Run the app on an emulator or device

## Features
- Splash Screen
- Admin & Parent Login
- Daily Meal Module
- Facilities Gallery
- Student Stars
- Feedback System
- AI Translation (Kannada)
